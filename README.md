# 他在家

名字來自故事裡每個人看到燈亮著時心裡那句話：「他在家，沒事。」好結局的最後一句也是它。（資料夾和套件名稱仍是 `day-47`，那是最早的工作名稱。）

一個把時間倒回去的 3D 互動故事，談孤獨死：與外界和家人缺乏互動，離世後過了一段時間無人察覺，才被發現。

從一扇貼著「租」卻一直租不出去的門開始，玩家按住倒帶，一路走回阿誠退休那天；接著時間照原來的方向走一次，由玩家親手把那扇門打開；最後把大家的「下次」改成「這次」，回到同一扇門前，按一次電鈴。

文案裡不使用「凶宅」和「事故物件」這兩個詞。屋子被另眼看待這件事，用租不出去、看房的人繞著走來表現。

## 時間線

所有天數都從同一個起點算：阿誠（周文誠，85 歲，開了三十四年客運，65 歲退休後又回站裡幫忙了二十年）在餐桌邊倒下的「那一天」。時間軸分三段：

| 段落 | 章節 | 發生的事 |
|---|---|---|
| 他還在的 90 天 | 倒下前 90 天 | 退休那天。屋子很整齊 |
| | 倒下前 45 天 | 一整天沒有說話。電視從早開到晚，舊報紙開始疊起來 |
| | 倒下前 14 天 | 里長、女兒、鄰居各自說了「下次」。垃圾四天沒倒 |
| | 那一天 | 他趴在餐桌上，沒有再起來 |
| 沒有人知道的 90 天 | 倒下後第 1 天 | 里長站在門口按電鈴，鏡頭切到門後 |
| | 倒下後第 3 天 | 三個人找過他，沒有人進門 |
| | 倒下後第 30 天 | 訊息還在來，掛鐘還在走 |
| | 倒下後第 60 天 | 門外的生活照常：帳有人付、燈有人看見、電話有人打 |
| | 倒下後第 90 天 | 房東按了電鈴沒人應，不敢自己開門，報了警（門要等順著走那一次才打開） |
| 空下來的 47 天 | 被發現後第 4 天 | 清空之前：女兒和清潔公司把屋子裝進紙箱 |
| | 被發現後第 47 天 | 遊戲開場，門上貼著「租」 |

遊玩順序是倒著走，每往回一步都在回答上一章留下的問題。

## 流程

1. 倒著走：十一個章節，從「被發現後第 47 天」走回「倒下前 90 天」。
2. 順著走一次（`forwardPass`）：從退休那天自動播到第 90 天的傍晚。
3. 被發現（`discovery`）：員警和里長到了門口，玩家按住，用備用鑰匙把門打開。鏡頭先進到門後，再切到樓下：救護車、封鎖線、圍觀的鄰居在問「發生什麼事了？」。
4. 把「下次」改成「這次」，時間往前走，結局。
5. 桌上的報紙。
6. 走出門（`finale`）：晚上，同一扇門。四句都改了的話，門縫有光，玩家按電鈴，他來開門；不然門是暗的。最後的片名卡會列出四句「下次」各自變成了什麼（`mends[].echo`），這是整個故事的回扣：開場是一扇沒有人敲的門，結尾是一扇有人來開的門。

為了讓前後對得起來：電視從他倒下那晚一直開到被發現那天（所以門外的人聽得到聲音，以為他在家）；房東沒有自己開門，是等員警和里長到場；救護車到了沒有載人。

為什麼 90 天沒有人發現（改文案時請維持這幾個設定，細節寫在 `src/story.js` 開頭）：女兒外派新加坡、他重聽又常說「沒消息就是好消息」；水電和房租都是自動扣款；燈一直亮著，鄰居反而放心；他有女兒，所以不在獨居長者的列冊名單裡。

## 橋段

圓點除了文字，還可以帶出一段東西，全部寫在 `src/story.js` 每個圓點的欄位裡：

| 欄位 | 是什麼 | 用在哪裡 |
|---|---|---|
| `cards` | 一疊可以翻的紙 | 租屋網的降價紀錄、信箱裡的五封信 |
| `phone` | 他的手機（通知列表／撥不出去的電話／對話，含打了又刪的草稿） | 第 30 天、第 3 天、那一天、前 14 天、前 90 天 |
| `cut` | 切到另一個鏡頭再切回來 | 第 60 天手機在門後響、第 3 天從對面看這扇窗、第 1 天里長按電鈴、前 14 天陳太太提著柚子 |

四環都在的結局裡，那通電話要玩家自己按下「撥給小妤」才會繼續。

圓點另外還有 `tv: true`（打開電視）。

## 屋裡的擺設與「越來越亂」

`Scene.vue` 的 `buildHome`：電視櫃和蕾絲布、太太的照片、大同電鍋和熱水瓶、木頭長椅、茶几和茶具、電風扇、掛鐘、優良駕駛的獎牌、窗簾、藥盒。

同一個函式裡的 `o.mess` 是會越來越多的東西：疊起來的舊報紙、長椅上的衣服、便當盒、泡麵碗、空寶特瓶、門邊沒倒的垃圾、沒洗的碗、沒拆的藥袋。每樣東西有一個 0 到 1 的門檻，退休那天是 0，倒下那天是 1；倒帶時它們會一樣一樣消失。大家都關心他的那條時間線裡，屋子維持整齊。

## 結尾的報紙

結局之後，餐桌上有一份報紙，老花眼鏡壓在上面。點它會拿起來看（`Newspaper.vue`）：現實裡的數字（每一則可以點開）、今天可以做的事（可以打勾）、一張可以剪下來的訊息草稿、資料來源。更新數字時請一起更新來源連結。

## 配樂

`src/music.js`：一首很慢的 A 小調，鋼琴加一層很薄的弦樂，全部用 WebAudio 合成，沒有音檔。門外只有分解和弦，進到屋裡才有旋律；夜裡放慢；按住倒帶時音樂也倒著走；他活下來的那條時間線會轉成 C 大調。和弦與旋律都是檔案開頭的兩個陣列，可以直接改。

## 結局的因果

四個人的關心，各自是那天晚上救援鏈上的一環：

知道不能等（阿坤）→ 願意開口（小妤）→ 找得到人（里長）→ 進得了門（陳太太）

四環都在，他活下來。少了任何一環，那天晚上就卡在那裡：他還是走了，但當晚到第 2 天之間就有人知道，結局會標出少的是哪一環。

整個遊戲都在同一個全螢幕 3D 場景裡：封面是整理乾淨、門上貼著「租」的樓梯間；按下「開始遊戲」後四十七天快轉過去；尾聲的文字是一張蓋在屋子上的紙。

## 人物模型

人物不是在 three.js 裡用方塊拼的，是用 Blender 的 Python 腳本建的：`tools/build_people.py`。

```bash
blender --background --python tools/build_people.py   # 或在 Blender 的 Scripting 分頁打開、按 Run Script
```

它會產生 `src/assets/people.glb`（遊戲載入的檔案）和 `tools/people.blend`（想手動修可以從這裡改）。裡面有三個人：`acheng`（阿誠：汗衫、短褲、藍白拖、頭頂稀疏）、`man`、`woman`，身形和穿著都是腳本開頭 `PEOPLE` 裡的數字。

- 身體是沿著骨架長出來的（Skin 修改器＋細分），頭是一顆球捏出下顎、鼻子、眉骨、眼窩、嘴唇。
- 衣服、頭髮是把身體對應的區域複製一層往外推；下襬和袖口先用平面切過，邊緣是平的。
- 骨架 17 根骨頭，自動權重，每個頂點最多 4 個權重。
- UV 用 Smart UV Project 攤成一張不重疊的圖，烘一張 1024 的 AO 貼圖；材質是 `顏色 × AO`，匯出後就是 glTF 的 `baseColorFactor` + `baseColorTexture`。
- 材質名稱固定（Skin、Shirt、Pants、Hair、Shoe…），`Scene.vue` 的 `makeFigure` 靠名字替每個人換顏色，所以圍觀的九個人只用兩個模型。
- `makeFigure` 把舊的姿勢資料（軀幹、頭、肩、肘各一個角度）轉成骨頭的旋轉；模型載入失敗時會退回 `makeFigureProc`（用程式拼的人）。

## 材質

`Scene.vue` 開頭的 `makeTextures`：磁磚、磨石子、木頭、舊牆各有顏色、法線、粗糙度三張貼圖，都是用 canvas 畫出來的，沒有圖檔。方塊的貼圖座標以公尺為單位，所以同一組貼圖可以鋪在任何大小的東西上。色調映射用 ACES，另外有一張室內環境貼圖提供反射。

## 開始

```bash
npm install
npm run dev            # 開發
npm run build:single   # 輸出單一檔案 dist-single/index.html，可以直接點兩下打開
```

## 檔案

- `src/story.js`：全部的故事文字、章節、熱點的 3D 座標、四個結局。改文案只要改這裡。
- `src/components/Scene.vue`：Three.js 場景。整間屋子是 `day` 的函數（信箱、黃金葛、日曆、行事曆、未讀數、灰塵、燈），鏡頭路線和各時段光線也在這裡。圓點的位置由 `story.js` 裡的 3D 座標投影而來，並且會被限制在畫面內；新增圓點後請確認它在鏡頭看得到的地方。
- `src/App.vue`：流程（封面 → 倒著走十一章 → 順著走一次 → 開門、被發現 → 改掉下次 → 時間往前 → 結局 → 報紙 → 走出門）和按住倒帶。
- `src/components/Newspaper.vue`：結尾的報紙。
- `src/components/DayPage.vue`：日曆紙。
- `src/audio.js`：WebAudio 合成的音效（秒針、電鈴、手機鈴聲、鑰匙、開門、救護車、人聲），沒有音檔。
- `src/music.js`：配樂。
- `src/components/PhoneScreen.vue`、`CardDeck.vue`：他的手機、一疊信。

開發時不用每次從頭玩：網址後面加 `#mend` 直接跳到最後的選擇，加 `#ch=6` 直接跳到第 7 個章節（從 0 算到 10，6 是電鈴那一章）。另外還有 `#true`（從順著走那一次開始）、`#open`（被發現那天的門口）、`#final`（最後一個畫面，四句都改了）、`#final=2`（只改前兩句）。例如 `http://localhost:5173/#ch=6`，改完網址後要重新整理。
